# Tinolandia-Proxy-Wars
The source code for the geoplotical stragey game from Ashley Buzuzi. A web based game where you face against 10 other nations in attempt to become the ruler oof the entire world.

It is a single player web game against 9 other countries on who can take control of all 10 countries. Base soldiers are predetermined by population. You strategize against nations, decide whether to fully attack or abstain a move. A game for the brain that test your problem solving skills and intuition on the biggest stage.

**Technologies**
Database: Firebase
Backend: Python, CSS and JavaScript
Frontend: Streamlit
LLM: Groq Language Processing Unit
Graphics: LDtk
